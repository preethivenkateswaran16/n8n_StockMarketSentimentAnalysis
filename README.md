# n8n_StockMarketSentimentAnalysis
An automated stock analysis platform that combines technical indicators, market data, news sentiment analysis, and AI-driven reasoning to generate actionable investment insights.

The system gathers real-time stock information, evaluates technical signals using rule-based analysis, analyzes market sentiment from recent news, and produces structured recommendations such as Buy, Sell, Hold, or Watch.

Key Features:
Automated stock data collection via finance APIs
Historical price and volume analysis
RSI (Relative Strength Index) calculation
Moving Average analysis
Real-time news aggregation
AI-powered sentiment analysis of market news
Rule-based technical evaluation
AI-assisted investment recommendation generation
Automated email reporting

Workflow:
Stock List Input → Market Data Collection → Technical Indicator Calculation → News Aggregation → Sentiment Analysis → Rule-Based Evaluation → AI Recommendation Generation → Email Report Delivery

Output:
For each stock, the system generates
Current Market Price
Trading Volume
RSI & Moving Average Signals
News Sentiment (Bullish / Bearish / Neutral)
Recommended Action (Buy / Sell / Hold / Watch)
AI-Generated Explanation

Rather than relying solely on an LLM, the platform first performs objective rule-based analysis using technical indicators and market data. The AI layer then combines these structured signals with news sentiment to provide contextual recommendations and explanations.

Business Impact:
Reduces manual stock research time
Combines quantitative and qualitative analysis
Delivers consistent monitoring across multiple stocks
Provides explainable recommendations backed by technical signals and market sentiment
Enables automated market intelligence reporting

Technologies:
Finance APIs
News APIs
Technical Analysis (RSI, Moving Averages)
Sentiment Analysis
LLM-Based Reasoning
Workflow Automation
Automated Email Reporting

Result:
A hybrid AI and rule-based stock intelligence system that transforms market data and news signals into actionable investment monitoring reports.
